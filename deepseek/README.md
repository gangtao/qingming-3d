# DeepSeek 版

来自 DeepSeek 网页版（chat.deepseek.com）的一次对话，开了联网搜索。模型自称“DeepSeek 最新版模型”，没有给出具体版本号。它没有运行环境，不能自己构建、截图或自查。

过程是多轮的：给出合并提示词后，它先出布局定标版，然后在“已确认”“继续”“先做细节”“做性能优化”“先修旋转轴 然后继续做细节”这类简短回复的推动下一步步做，共 13 轮（另有开头一句问它是什么模型），每轮都重新给出一份完整的单页 HTML。原画参照图的 GitHub 链接它打不开，全卷图是后来在对话里另外附上的。

- `index.original.html`：它最后一次给出的完整 HTML，原样保存。打开是黑屏，报错 `TypeError: THREE.CapsuleGeometry is not a constructor`：它指定加载 three.js r128，但 r128 里没有 `CapsuleGeometry`（驴马的身子和头用到了）。
- `index.html`：修复后的版本，便于对照观看。只做了两处改动，页面自身的代码一行没动：把从 cdnjs 加载 three.js r128 换成内嵌同一个文件（离线可看）；在它后面加了一小段脚本，给 r128 补一个同参数的 `CapsuleGeometry`（用旋转体做的胶囊形）。
- `build.js`：它在做界面那一轮给的构建脚本（把 three.js 内联进去），原样保存，没有运行过。
- `preview/`：用修复后的 `index.html` 截的图。

修复后的页面加载时实际创建了 148 个人物、9 头牲口（驴和马）、6 条船、29 座房屋，另有城门 1 座、虹桥 1 座、彩楼 1 座、柳树 14 棵。触屏的双指缩放和旋转它自己说明了没有接上。

用量：网页版不显示 token 数和每轮用时，都无法统计。能数的只有文字量：14 次回答合计约 33.8 万字符（最后一份 HTML 约 4.2 万字符）。
